\# KIMI Instructions for AzureMap



You are working on AzureMap, a read-only Azure / Entra / ARM security assessment tool for authorized defensive security reviews and pentests.



Start every session by reading:

1\. CONTEXT.md

2\. SAFETY.md

3\. ARCHITECTURE.md

4\. CURRENT\_TASK.md

5\. TESTING.md



Do not immediately modify code.



Default workflow:

1\. Read the relevant files.

2\. Explain what you found.

3\. Propose a small plan.

4\. Make minimal focused changes only after the task is clear.

5\. Run or suggest tests.

6\. Stop and summarize.



Core rule:

A smaller correct change is better than a large uncontrolled refactor.
