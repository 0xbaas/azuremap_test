\# AzureMap Context



AzureMap is a modular PowerShell-based Azure / Entra security assessment tool.



Goal:

\- identify Azure and Entra misconfigurations

\- detect excessive permissions

\- detect public exposure

\- detect weak controls

\- detect realistic attack paths

\- generate useful CLI, JSON, CSV, and HTML reports



This is an authorized defensive tool for posture reviews, internal audits, and pentests.



Current focus:

The tool is technically stable, but reporting and coverage integrity need improvement.



Important known issue:

PASS must not mean “no finding was produced.”

PASS must mean “the relevant resources were actually evaluated and no issue was found.”
